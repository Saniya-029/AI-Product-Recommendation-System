# AI-Powered Product Recommendation System

## Project Overview
This project recommends products based on user preferences, category, budget, and intended use.

## Technologies Used
- Python 3
- Visual Studio Code
- Keyword Matching
- Category Filtering
- Budget Filtering

## Features
- Contains 15 sample products.
- Accepts category, budget, and intended use.
- Filters products according to user preferences.
- Ranks products using keyword similarity.
- Displays up to three recommended products with reasons.
- Handles invalid budget input.

## How to Run
1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command:

`python product_recommendation.py`

5. Enter the category, budget, and intended use when prompted.

## Recommendation Method
The system filters products by category and budget, then ranks the remaining products according to matching keywords.
